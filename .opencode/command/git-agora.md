description: Commita e publica as alterações atuais no GitHub (atalho para a skill git-agora).
---

Execute o fluxo da skill `git-agora`: inspecione `git status`/`git diff`, valide a sintaxe, faça stage respeitando o `.gitignore` (nunca commite segredos), commite e faça push para `origin main`. Mensagem do commit: $ARGUMENTS (se vazio, resuma as mudanças em uma linha). Ao final reporte o hash e lembre do deploy automático em ~1-2 min.
